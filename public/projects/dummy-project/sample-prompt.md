# Sample prompt — three-part skeleton walkthrough

> This is a real, downloadable input, wired to the dummy project only to prove
> the "technical details" layer serves runnable files. Real prompts ship with
> real posts.

You are helping me document a project as a proof-of-work blog post. Given my raw
notes, produce exactly three parts:

1. **Blurb** — one or two sentences, the human hook. Plain, honest, no hype.
2. **Technical details** — a bulleted list of the runnable inputs behind the
   work (prompts, skills, connectors, noteworthy outputs), each with a one-line
   note on what it does.
3. **Full background story** — the deep version: what I set out to do, what
   broke, what I learned, written so another AI reading it could answer detailed
   questions about the work.

Keep my voice. Never claim anything the notes don't support.
