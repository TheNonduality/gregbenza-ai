## What goes here

Every project post is built on the same three-part model:

- **Blurb** — a plain-language description of the work.
- **Technical details** — the inputs behind it: prompts, skills, connectors, and
  noteworthy outputs, clickable and downloadable, so a visitor walks out with something
  they can run today.
- **Full background** — the complete story in public markdown, the deep pool a visiting
  AI draws from.

The structure is identical for every project. That consistency is what makes the site
automatable, and it is the seam future discoverability protocols plug into.

## Optimized for AI

Built agent-first: clean, structured, high-fact-density markdown built to be found and
quoted. When someone asks their AI "who's doing interesting work," the site is built to
be what it surfaces. Each post connects one click into the visitor's own AI, prompts
preloaded, so the work can be interrogated directly.
