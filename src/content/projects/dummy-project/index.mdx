## What lands here

The census is still counting, so this slot's a stand-in. But the shape is real, and
every project fills it the same way — that sameness is what lets the site keep
publishing itself.

Three layers, every time:

- **The hook** — what it is, in plain language, up top. (You just read one.)
- **The runnable pieces** — the prompts, skills, and connectors behind the work,
  clickable and downloadable, so you leave with something you can actually run, not
  just something you looked at.
- **The full story** — the deep version underneath, written so a visiting AI can read
  it and answer real questions about the work.

Media rides with the work, too — a real image up top, and a clean embed right here,
loaded only when you click it:

## Showing is only the floor

The aim is a site that hands the work over — and one you can talk back to. Tell me what
you'd build differently, and the next version gets better for it.

A year of real projects, big and small, starts landing here once the census counts
them. This spot won't be empty long.
